## Stack

- Angular 19
- Tailwind CSS
- Design system próprio (`ax-*`), tema escuro fixo

## Como rodar

```bash
npm install
ng serve
```

Navegue para `http://localhost:4200/`. Para build de produção:

```bash
ng build
```

## Requisitos

- Node.js e npm
- Angular CLI (`npm install -g @angular/cli`)
